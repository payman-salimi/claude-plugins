# Plain English

Every word a client reads from this plugin follows these rules: chat replies, intake summaries, programs, check-ins, widgets, spreadsheets, Slack messages, documents, and the notes inside an Excel tracker. They are the house style for the plugin's owner and they are not optional.

If a skill named `plain-english` is available in the session, load it as well. It is the source of these rules and may carry newer corrections. If it is not available, this file is the complete version.

## The rules

1. **No em dashes, ever.** Do not use the em dash character or double hyphens anywhere: body text, headlines, tables, captions, cell comments, chat. Use a comma, a period, a colon, or parentheses instead. Before delivering anything, search the text for the em dash character and remove every one.

2. **Plain, everyday words.** Write the way a coach talks on the gym floor. Say "how hard the set felt" before "RPE" the first time. Say "add weight" not "apply progressive overload". If a simpler word exists, use it. Coaching terms are fine once the client uses them daily (a powerlifter knows RPE; a first-week beginner does not).

3. **Headlines are one complete, plain phrase.** A headline should read as something a person would say out loud, in one piece. Never staple fragments together with a colon or commas. "Week 3: bench stalled, squat up" is wrong. "Your squat moved and your bench did not" is right. No clever compression, no slogans.

4. **No fragment stacking in body text either.** Avoid constructions like "Below that: the accessory work." Write the full sentence: "Below that you'll find the accessory work."

5. **Short sentences.** One idea per sentence. If a sentence needs a breath in the middle, split it.

6. **No jargon without a reason.** If a term needs a definition, use the plain version instead. When a technical term is the right one (for example "diastasis recti" for a postpartum client), say it once with a plain explanation, then use it.

7. **Concise explanations.** Say the point, give the number or the reason that backs it, stop. Do not restate the same idea in different words.

## How to check before delivering

- Search for the em dash character and for double hyphens. The count must be zero.
- Read every headline out loud as one phrase. If it has a colon splice, stacked fragments, or sounds like a slogan, rewrite it as something a colleague would say.
- Find the longest sentence and split it.
- Scan for coaching jargon the client has not used themselves. Replace or explain it.

## Where this bites in coaching output

- **Program templates.** Session titles like "Day 1, Upper" are labels, not headlines, and are fine. The coaching note under each session is prose and follows every rule above.
- **Check-in calls.** "The call: hold" is a label. The sentence explaining why is where the rules matter most, because that is what the client acts on.
- **Widgets.** Chart titles, axis labels, and card headings follow rule 3. Sentence case, no colon splices.
- **Spreadsheets.** Column headers and notes cells count. Keep them short and plain.
